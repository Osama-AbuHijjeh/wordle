# Terminal Wordle

A Wordle game for the terminal, written in Python while I was learning.

## How to play

You have 10 guesses to find a secret 5-letter word.

- 🟩 correct letter, correct spot
- 🟨 correct letter, wrong spot
- 🟥 letter not in the word

## Run it

```
pip install -r requirements.txt
python wordle.py
```
